\# Sample Data



This folder contains fully fake data for testing the Academic Intervention Sorter.



\## Files



\- `progress\_report.xlsx` — fake progress report data

\- `contact\_report.xlsx` — fake contact data

\- `groups/control.txt` — group processing order

\- `groups/\*.xlsx` — fake prioritized intervention groups



\## Notes



The sample data is randomly generated and does not contain real student information.



Use this data to test the app without using institutional exports.
