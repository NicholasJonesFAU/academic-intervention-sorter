# \# Academic Intervention Sorter# # A desktop application designed to streamline academic intervention workflows by processing student outreach and risk-reporting data into organized intervention groups, campaign reports, and advising analytics.# # Built with Python and PyQt5, this tool was created to support operational workflows commonly used in higher education advising environments.# # \---# # \## Features# # \### Intervention Sorting# # \* Sorts at-risk students into prioritized intervention groups# \* Processes multiple list files in a specific order# \* Prevents duplicate assignment across groups# \* Preserves all associated course records for matched students# # \### Midterm Grade Processing# # \* Processes midterm grade reports# \* Identifies at-risk students# \* Supports intervention campaign workflows# \* Exports organized Excel outputs with multiple tabs# # \### Campaign \& Trend Analysis# # \* Campaign tracking tools# \* Trend analysis dashboards# \* Faculty report status monitoring# \* Progress reporting utilities# # \### User-Friendly Desktop Interface# # \* Multi-tab PyQt5 GUI# \* Configurable settings# \* Export management# \* Built-in help/documentation tools# # \---# # \## Tech Stack# # \* Python# \* PyQt5# \* pandas# \* openpyxl# \* Excel/CSV data processing# # \---# # \## Project Structure# # ```text# academic-intervention-sorter/# │# ├── assets/              # Application assets and resources# ├── docs/                # Documentation and release notes# ├── processors/          # Core processing logic# ├── utils/               # Shared utility functions# ├── main.py              # Application entry point# ├── requirements.txt# └── README.md# ```# # \---# # \## Example Workflow# # 1\. Load:# # &#x20;  \* Midterm grade reports# &#x20;  \* Contact reports# &#x20;  \* Intervention list files# # 2\. Configure intervention order# # 3\. Run processing pipeline# # 4\. Export:# # &#x20;  \* Sorted intervention groups# &#x20;  \* Campaign outputs# &#x20;  \* Faculty status reports# &#x20;  \* Trend analysis results# # \---# # \## Installation# # Clone the repository:# # ```bash# git clone https://github.com/NicholasJonesFAU/academic-intervention-sorter.git# cd academic-intervention-sorter# ```# # Install dependencies:# # ```bash# pip install -r requirements.txt# ```# # Run the application:# # ```bash# python main.py# ```# # \---# # \## Screenshots# # Add screenshots of:# # \* Main dashboard# \* Midterm sorter# \* Campaign manager# \* Trend analysis tools# \* Output examples# # \---# # \## Purpose# # This project was created as a portfolio and workflow automation tool inspired by real-world higher education advising operations.
